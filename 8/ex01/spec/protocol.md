# smesh
(smesharik mesh protocol TM)

## Ноды
Нода - хост в распределенной сети:
- адрес
- uuid - генерируется нодой при инициализации

## Связь нод
У каждой ноды есть список "known hosts" - то, куда нужно отправить пульс в нужный момент. \
Список содержит последнее время, когда с этого хоста был входящий пульс. \
В момент обхода списка это время будет проверено, и если оно больше, чем 2х Tпульса, хост считается отключенным.

## Подключение новой ноды в сеть
- запросить у известной ноды и сохранить у себя список ее известных хостов
- отправить пульс
